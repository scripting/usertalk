# hello

The smallest UserTalk program -- a handler with a default parameter, and two calls to it.

To run it, from the top of this repo:

```
node code/run.js examples/hello/hello.opml
```

And it says:

```
Hello, World!
Hello, Dave!
examples/hello/hello.opml: 2 verb calls (ok)
```

The script is an outline, stored as OPML -- in Frontier you'd be looking at it in the outliner, each line a node, the handler's body indented under it.
